Drag on the canvas to move whichever element you last touched — grab the runner or the tile directly. Everything else is on the sliders. The little previews are the real sizes an icon gets used at; if he stops reading at 32 the composition is too busy.

Mask cycles square → rounded → circle so you can check iOS and Android cropping, and Safe area rings the region every platform keeps. Keep the runner inside it.

Save writes PNGs named icon-1024.png and so on, matching what the manifest already expects — drop them straight into the project folder. Exports are always full-bleed squares, whatever the mask preview is showing, because iOS and Android round the corners themselves.

The composition autosaves to this browser, so closing the tab doesn't lose it. Reset clears the save and goes back to the shipped defaults.
